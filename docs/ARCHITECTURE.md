# 架构与数据边界

浏览器 → `server/gateway.cjs` → Next.js 网页／API → 受配置和 SSRF 规则限制的第三方服务。

- 网关读取真实 TCP 对端地址，覆盖客户端伪造的转发头；后台要求回环地址及 localhost Host。
- 后台会话与观影会话分开，普通用户的 Cookie 不能进入管理 API。
- 观看历史从签名会话确定账号，客户端账号标识只用于拒绝切换账号后的旧页面请求，不能指定其他账号的数据文件。
- 退出／切换账号清理页面查询缓存并通知其他标签页；最近搜索按账号分库，不回退到旧共享数据。
- 推荐和影视详情缓存不包含用户的个人进度；第三方内容仍受外部服务稳定性和授权限制。
- SMTP 和可选字幕进程均在部署者环境执行；不会使用作者的个人邮箱或模型目录。
- 网关只统计本机服务写出的响应正文；浏览器直接请求的媒体不计入，因此不等于整个家庭网络流量。

这不是多租户云服务或完整安全审计结果。请使用独立强密码、保管私有数据，并在改变部署边界时重新检查访问控制。
